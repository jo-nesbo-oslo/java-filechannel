El concepto de eliminación de archivos se muestra aquí. Esto se hace con un simple comando del método File.delete().

El método Java File delete() se puede usar para eliminar archivos, devolverá un valor booleano. Devuelve verdadero si se elimina el archivo; falso si falla.
